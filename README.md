# 🌐 Project 1 - Responsive Portfolio Website

This project is created as part of my **Decodelabs Internship**.

## 🚀 Project Overview

A responsive portfolio website built using **HTML, CSS, and JavaScript**.  
The website works smoothly on mobile, tablet, and desktop devices.

## 🎯 Features

- Responsive design (Mobile-first approach)
- Clean and modern UI
- Navigation bar with mobile menu
- Hero section with introduction
- About section
- Skills section
- Projects showcase
- Contact form with validation
- Footer section

## 🛠️ Technologies Used

- HTML5 (Semantic structure)
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (DOM manipulation, form validation)
